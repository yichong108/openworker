# 将 OpenWorker 约定从 packages/agent 抽到 Native

## Task Status

DONE

## Task Priority

P1

## Task Dependencies

- None

# Human Notes

## Context

- `packages/agent` 原先耦合 OpenWorker 产品约定（Skills/MCP 路径、进程单例、AG-UI 产品类）。
- 需要拆成通用产品 `createAgent` + Native 产品层 `OpenWorkerAgent` / `OpenWorkerAgentAGUI`。

## Requirements

- 通用 `packages/agent`：仅 `createAgent`、工作区工具、composerMode、plan 工件；无 MCP、无 AG-UI。
- Native `OpenWorkerAgent` 直接引用 `createAgent`，独享 MCP 与 Skills/MCP 约定加载。
- Native `OpenWorkerAgentAGUI` 持有 `OpenWorkerAgent`，自定义实现 AG-UI（不经过 `AgentWithAGUI`）。
- Native 会话 / MCP host / `ask` 一律经 `OpenWorkerAgentAGUI`，不得直接持有 `OpenWorkerAgent`。
- 删除 `packages/uni-agent`。

## Constraints

- 不改会话互斥、记忆、SSE 协议。
- `base-agent` 的 `BaseAgentWithAGUI` 不动。

# Agent Notes

## 完成说明

### packages/agent（通用产品能力）

- `createAgent` 改为注入式：`resolveCapabilities` 提供额外 `ToolSet` 与 `promptExtras`（`skillHint` / `extraPrompt`）。
- 去掉 MCP、`AgentMcp`、进程单例、AG-UI 产品类（`AgentWithAGUI` 等）及 `@openworker/mcp`、`@openworker/skills`、`@ag-ui/client`、`rxjs` 依赖。
- `workspace-tools` 去掉 MCP 元工具 prompt；工作区根须显式传入，去掉 `process.cwd()` 回退。
- `send` 使用 `toolsMode: 'replace'`，避免 base-agent 再合并 shell。

### services/native（产品层）

- 新增 `openworker-agent.ts`：`createAgent` + 自有 `mcp` API。
- 新增 `openworker-agent-agui.ts`：`extends AbstractAgent`，持有 `OpenWorkerAgent`，自定义事件映射。
- 新增 `skills-mcp.ts`、`singletons.ts`、`ask.ts`。
- `agent-instance.ts`、`session-auto-name.ts` 改引用 `OpenWorkerAgentAGUI`。

### 删除

- `packages/uni-agent` 整包。
