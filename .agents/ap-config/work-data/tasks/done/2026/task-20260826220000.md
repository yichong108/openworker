# Human Notes

## Context

- 用户安装 `@openworker/ap` 后，需要一条命令打开 ap-web 任务看板，读写当前项目的 `.agents/`。
- ap-web 需独立发布为 standalone；monorepo 本地开发仍用 `pnpm ap-web:dev`（:3011），`ap view` 不做 dev 分支。
- 多项目并行时各目录独立 ap-web 实例，端口需自动分配并持久化。

## Requirements

- ap-cli 内建 `ap view`：检测/启动 `@openworker/ap-web` standalone，打开浏览器。
- ap-web 可 npm 发布：`next build` standalone + prepare-standalone staging + 临时 package.json。
- `GET /api/health` 返回 `{ ok, launchDir }` 供多实例识别。
- 端口扫描 10000–10099（`AP_WEB_PORT_MIN` / `AP_WEB_PORT_MAX` 可覆盖）；每项目 `.agents/ap-config/web-data/ap-web.port` 持久化。
- 注入 `INIT_CWD` 对齐用户项目根。

## Constraints

- 源 `apps/ap-web/package.json` 保留 `private: true` 与 `workspace:*`；发布 manifest 由脚本临时生成。
- `view` 不需要 Cursor 鉴权。
