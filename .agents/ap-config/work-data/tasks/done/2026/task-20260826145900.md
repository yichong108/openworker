# Human Notes

## Context

- `apps/ap-web` 任务 Agent 与 skill 执行原先直接依赖 `@cursor/sdk` 的 `Agent.create`。
- 产品方向改为仅使用 DeepSeek，底层 Agent 通过 `@openworker/ap-agent` 的 `ApAgentWithAGUI` 创建。

## Requirements

- 移除 ap-web 对 `@cursor/sdk` 的依赖与 Cursor 登录/配置 UI。
- 使用 `@openworker/llm` 的 `getChatModel` 解析 DeepSeek 配置，传入 `ApAgentWithAGUI`。
- 重写 `task-agent-runner.ts`、`skill-runner.ts`，AG-UI 事件映射到现有 SSE 聊天 transcript。
- AI 配置精简为仅 DeepSeek（apiKey + model）。

## Constraints

- `/api/tasks/[...id]`、`/api/tasks/chat/stream`、`/api/skills/run|stop` 对外行为不变。
- 不修改 plan 文件。
