# 修复 task-create 写入 todo/ 而非 active/

## Task Status(Required)

DONE

## Task Priority(Required)

P1

## Task Dependencies(Required)

- None

## Context(Required)

`ap task-create`（含 `ai-pipeline:task-create`）仍把任务文件写到 `tasks/active/`，与 work-data 约定的 `todo/` 不一致。

## Requirements(Required)

- 执行 `ap task-create`（含 `ai-pipeline:task-create`）时，在 `tasks/todo/` 下创建任务文件，而不是 `tasks/active/`
- 帮助文案与种子 README 中关于创建位置的说明与上述行为一致

## Constraints(Required)

- None
- 不引入新的依赖
- 不修改 ADR

## Agent Notes

`createWorkDataFile` 与 CLI 帮助改为写入 `tasks/todo/`。未改 ADR。

## Completion

### Implementation

- `ap/src/create-work-data.ts`：task 目标目录由 `tasks/active/` 改为 `tasks/todo/`
- `ap/src/cli.ts`：帮助文案同步为 `tasks/todo/`
- `ap/src/work-data/README.md`：种子约定改为创建到 `todo/`；种子增加 `todo/.gitkeep`，移除 `active/`
- `ap-task-execute` / `ap-refactor`：TODO 目录由 `active/` 改为 `todo/`，与创建位置一致

### Validation

- `pnpm lint:fix`：通过
- `pnpm --filter @openworker/ap typecheck`：通过
- `pnpm --filter @openworker/ap build`：通过
- `pnpm ap:start:dist task-create --name _verify-todo-create-20260825`：文件落在 `tasks/todo/`（验证文件已删除）
- `pnpm ap:start:dist help task-create`：文案为 `tasks/todo/`

### Notes

- 用户在对话中当场给出本任务需求，按技能「先写入 TASK 再执行」
