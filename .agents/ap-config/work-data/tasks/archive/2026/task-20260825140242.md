# 未填写任务转入 blocked，P0 阻塞则停止队列

## Task Priority(Required)

## Task Dependencies(Required)

## Context(Required)

执行 `active/` 任务时，空白模板会被当成可执行需求，容易猜着做。P0 表示紧急且阻塞其他工作，一旦执行中卡住，继续做低优先级任务会把阻塞问题晾在一边。

## Requirements(Required)

- 执行任务遇到未填写的 task，将该任务文件转到 `blocked/`，不要猜着补全或执行
- 若 P0 任务在执行过程中阻塞（含因未填写或其他原因移入 `blocked/`），其他任务都停止执行
