# 项目根目录添加publint

## Status

COMPLETED

## Priority

P1

## Dependencies

- task-20260824080812

## Decision Needed

- None

## Context

为了让发布到npm上的包的质量更高，可用性更强以及减少发布的错误成本。

## Goal

使用publint在发布前进行校验

## Scope

### In Scope

- 根目录安装 publint
- ap 与 packages/skills 添加 publint 脚本

### Out of Scope

- 不要把packages\skills\openworker-skills发布出去，就是说npm包产物不应该包含packages\skills\openworker-skills

## Requirements

- 目前是需要在项目根目录下安装publint;
- 在ap目录和packages\skills下的package.json添加publint命令；

## Constraints

- None

## Acceptance Criteria

- [x] 根目录 devDependencies 含 publint
- [x] `ap` 与 `packages/skills` 均有 `publint` 脚本且可执行
- [x] `@openworker/skills` publint 通过，`pnpm pack` 不含 `openworker-skills/`
- [x] `@openworker/ap` publint 无 error（仅 suggestion）

## Related Decisions

- None

## Completion

### Implementation

- 根目录 `pnpm add -D -w publint`
- `ap/package.json`、`packages/skills/package.json` 添加 `"publint": "pnpm run build && publint"`
- 调整 `packages/skills` 的 `exports`/`types` 指向 `dist`，并启用 `declaration` 以满足 publint

### Tests

- `pnpm --filter @openworker/skills test`：15 项全部通过

### Validation

- `pnpm --filter @openworker/ap publint`：仅 suggestion，exit 0
- `pnpm pack`（skills）： tarball 仅含 `dist/`、`README.md`、`package.json`，不含 `openworker-skills/`
- `pnpm lint:fix`：通过
