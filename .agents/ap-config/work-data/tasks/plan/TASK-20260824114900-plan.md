# 升级 AI SDK 与 Zod 到最新

## Status

COMPLETED

## Priority

P1

## Dependencies

- None

## Decision Needed

- None

已确认：升到 AI SDK 7 + 匹配的 `@ai-sdk/openai` 4.x，并同步 catalog 中的 zod 到 4.x；`packages/*` 对外接口不改。

## Context

pnpm catalog 中 `ai` 为 4.x、`@ai-sdk/openai` 为 1.x、`zod` 为 3.x。AI SDK 最新为 7.x，跨多个主版本，消息/工具/流式字段有破坏性变更。需要在包内消化 SDK 变化，避免把 breaking 漏到 packages 对外 API。

## Goal

共享依赖升到当时最新的 AI SDK 与 Zod；OpenAI 兼容 Chat Completions 通道与 ReAct 手动工具循环语义保持不变。

## Scope

### In Scope

- catalog：`ai`、`@ai-sdk/openai`、`zod` 与 lockfile
- 包内适配：`stream-chat`、`defineTool` 映射、`react-loop`、AG-UI 消息转换、native `maxOutputTokens`
- Zod 4 破坏点（如 MCP `passthrough` / `looseObject`）

### Out of Scope

- 不升 `@ag-ui/*`
- 不做内置 shell 工具重构（见 `TASK-20260824082104-plan.md`）
- 不为再导出的 `Tool` / `ToolSet` / `LanguageModel` 再包一层公开 API

## Requirements

- 只改 catalog + lockfile，子包继续 `"catalog:"`
- `packages/*` 已 export 的函数名、入参形状、返回字段名、类型名保持不变
- `CoreMessage` / `CoreAssistantMessage` / `CoreUserMessage` 仍为导出名（内部 alias 到 `Model*`）
- `defineTool` 调用方仍传 `parameters`，封装层映射 `inputSchema`
- `getChatModel` 继续 `createOpenAI(...).chat(model)`，不改默认 Responses API
- ReAct 继续 `toToolDeclarations` 去掉 `execute`，`maxSteps` 仍为本仓库循环上限

## Constraints

- 不改 packages 对外接口
- 不引入新的公开 API 名称

## Acceptance Criteria

- [x] lockfile 中 `ai@7.x`、`@ai-sdk/openai@4.x`、`zod@4.x`
- [x] `pnpm typecheck` 通过
- [x] `packages/llm`、`tools`、`agent`、`skills` 单测通过
- [x] 未改 AG-UI 依赖；未做 shell 内置工具替换
- [x] 公开 export 名称与 `defineTool` 的 `parameters` 等入参字段不变
