# OpenWorker

OpenWorker is your AI companion for everyday information processing, helping you make better choices.

## Preview

OpenWorker main UI

## Prerequisites

- [Node.js](https://nodejs.org/) **18+**
- [pnpm](https://pnpm.io/) **9**

## Install

```bash
pnpm install
```

## Development

### Run core apps in dev mode

```bash
pnpm dev
```

### AI Coding

See [AGENTS.md](AGENTS.md), [.ai/README.md](.ai/README.md), [skills/](.cursor/skills/) 。
For example, running the /se-task-executor skill to quickly get started with development.
