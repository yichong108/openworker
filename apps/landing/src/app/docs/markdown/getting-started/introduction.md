# 简介

OpenWorker 是你的 **日常信息处理 AI 伙伴**：帮你提问、整理、在工作区里完成任务，并尽量把数据留在本地。

## 它能帮你做什么

- **对话与执行**：不只是聊天，还能读写文件、调用工具、推进具体任务
- **工作区（Workspace）**：把项目文件夹当作上下文，让回答贴合你正在做的事
- **Skills（技能）**：在输入框输入 `/`，选择排错、代码评审、工作流等技能
- **知识库**：结合已录入的资料回答问题
- **记忆**：长对话会压缩要点；系统也会记住你的偏好与项目相关信息，让后续更省力
- **多端**：桌面端是主力；另有移动端可配套使用

## 适合谁

- 希望有一个本地优先、隐私更友好的 AI 助手
- 需要围绕真实项目文件夹工作，而不是空对话
- 想通过 MCP 接入自己的文件、服务或内部工具
