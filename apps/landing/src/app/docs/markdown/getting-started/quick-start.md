# 快速开始

最短上手路径。产品背景见 [简介](#introduction)。

## 发出第一条消息

1. **启动应用**：打开 OpenWorker 桌面端
2. **打开 Workspace**：选择或新建工作区（指向你的项目文件夹）
3. **开始对话**：在输入框提问或下达任务
4. **（可选）调用 Skills**：输入 `/`，选择技能（如排错、代码评审）

## 基础操作

### 发送消息

输入问题或指令后发送。助手可能调用工具；界面时间线会展示思考与操作过程。

### 使用工具与 MCP

在已配置 MCP 的前提下，助手可访问文件、外部服务等能力。配置说明见 [MCP 协议支持](#mcp-support)。

### 会话与记忆

对话会保存；较长会话可能被压缩要点。若启用画像相关能力，后续对话会更贴合你的习惯与项目。
