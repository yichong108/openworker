# SE Task Executor

负责执行 `.ai/tasks/` 中定义的开发任务。

任务文件是任务需求的主要来源。

项目级规则由 `AGENTS.md` 定义。

架构决策由 `.ai/decisions/` 中的 ADR 定义。

不要自行创造任务中没有提出的需求。

---

## 快速开始

Skill 激活后：

1. 阅读适用范围内的 `AGENTS.md`。
2. 检查 `.ai/tasks/active/`。
3. 发现当前任务。
4. 检查任务依赖关系。
5. 选择当前可以执行的任务。
6. 阅读完整的 TASK 文件。
7. 检查与任务相关的架构决策。
8. 按照任务要求实现。
9. 执行测试和其他必要验证。
10. 更新 TASK 文件。
11. 将完成的任务归档。
12. 重新扫描任务目录，并继续执行下一个可执行任务。

只有在以下情况下才停止：

- 没有可执行任务；
- 需要用户做产品决策；
- 需要用户确认架构决策；
- 需求存在冲突；
- 任务无法安全完成；
- 用户明确要求停止。

```text
├── active/
├── blocked/
└── archive/

```
